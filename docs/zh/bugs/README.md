# AddressForge Bug 文档目录

本目录用于集中管理 AddressForge 的功能缺陷、运行时错误、任务编排问题和系统行为异常说明文档。

## 使用原则
- 这里记录的是 **功能性问题 / Bug / 运行缺陷**
- 不记录纯产品体验讨论
- 不记录产品方案设计
- 每个问题应尽量单独成文，便于架构师和开发者直接理解并修复
