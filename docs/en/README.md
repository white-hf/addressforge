# AddressForge Documentation Hub

AddressForge is an open-source, self-hosted address intelligence platform. It ships with a default Canada / North America model and can be adapted to private address data, custom models, and self-hosted API deployments.

The English docs are now organized into professional delivery categories:

- `getting-started/`
- `product/`
- `architecture/`
- `ml/`
- `delivery/`
- `operations/`
- `governance/`
- `bugs/`
