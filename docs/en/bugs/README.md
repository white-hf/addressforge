# AddressForge Bug Documentation Directory

This directory is used to centrally manage AddressForge functional defects, runtime errors, task orchestration issues, and system behavior bug documents.

## Usage Rules
- This directory is for **functional issues / bugs / runtime defects**
- It should not be used for pure product experience discussions
- It should not be used for product solution design proposals
- Each issue should preferably be documented as a standalone file so architects and developers can understand and repair it directly
